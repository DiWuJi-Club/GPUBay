# AI 管家

- **能做什么**：帮您挑选套餐和可租时段、租用或续费实例、取消预订、释放实例；在实例上部署 / 重新部署 / 停止 / 启动 / 卸载应用；读取部署日志与事件帮您排查问题；查询余额、订单与计费规则，回答帮助页里的问题。
- **不能做什么**：查看或修改 SSH 密码、管理 SSH 公钥、开放 / 公开 / 删除端口、已有实例的自动续费开关、充值、实名认证、邀请返利相关操作。遇到这些需求，管家会告诉您在控制台的哪个页面自己操作。
- **任何花钱或删除的操作都会先出确认卡**：卡片上的内容与金额由平台根据真实参数生成，您点「确认」才会执行，不点就什么都不会发生；释放实例、卸载应用、取消预订等危险操作还需要勾选确认。确认卡 10 分钟内有效。
- **对话保存 90 天**：客服在排障时可能查看对话内容；管家生成的密钥与应用的敏感变量不会以明文保存。
- **每日额度**：每个账号每天有一定的 AI 管家使用额度，用完后次日恢复。
- **价格以下单页为准**：管家回答里的价格来自实时查询，但最终扣款以确认卡与下单页显示的金额为准。
