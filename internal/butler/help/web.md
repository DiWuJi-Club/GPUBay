# Web 访问（端口开放）

- 在实例详情「Web 访问」添加端口后，会得到形如 `https://ins-xxxxxxxx-8888.…/` 的网址；默认**私有**：只有您在本站登录后才能打开。
- 设为**公开**后任何人都能访问，平台不做鉴权与限流，请确认应用自带密码；平台可在收到滥用举报后将端口限制为私有。
- 应用需监听 `127.0.0.1` 或 `0.0.0.0`（只监听容器 eth0 地址不通）。Jupyter 请用 `jupyter lab --ip=127.0.0.1 --port=8888 --ServerApp.allow_remote_access=True`，否则会提示 Host not allowed。
- 网址下的 `/.spark/` 路径由平台保留；应用自身的 CSRF 等安全防护由应用负责。
